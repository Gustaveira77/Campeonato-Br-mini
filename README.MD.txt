# Sistema de Mini Campeonato em MySQL

Projeto simples de modelagem e consultas SQL simulando uma tabela de classificação
de futebol.

# Tecnologias
- MySQL
- SQL puro

# Funcionalidades
- Cadastro de partidas
- Cálculo automático de pontos, saldo de gols
- Geração da tabela completa com todas as informações

## Conceitos aplicados
- Case
- Union all
- Group by
- Order by
- Subqueries
